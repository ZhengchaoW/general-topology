Continuity and Convergence

Convergence in Topological Spaces

We will try to answer the following questions:

  1. Can we define sequential convergence in general topological spaces?

  2. If so, does this convergence describe the notion of topology?

In metric space setting, we have the notion of convergence of a sequence (in the language of open balls):

Proposition 4.1 A sequence (xn)n∈N(x_n)_{n\in\mathbb{N}}(xn​)n∈N​ in a metric space XXX converges to a point x∈Xx\in Xx∈X if and only if for every ϵ>0\epsilon>0ϵ>0, there exists N∈NN\in\mathbb{N}N∈N such that xn∈Bϵ(x)x_n\in B_\epsilon(x)xn​∈Bϵ​(x) for all n≥Nn\ge Nn≥N.

This motivates the following definition in general topological spaces:

Definition 4.2 A sequence (xn)n∈N(x_n)_{n\in\mathbb{N}}(xn​)n∈N​ in a topological space XXX is said to converge to a point x∈Xx\in Xx∈X if for every neighbourhood UUU of xxx, there exists N∈NN\in\mathbb{N}N∈N such that xn∈Ux_n\in Uxn​∈U for all n≥Nn\ge Nn≥N.

Problem 4.3 A sequence (xn)(x_n)(xn​) in a metric space converges in the metric sense if and only if it converges in the topological sense defined above.

Proof. (⇒\Rightarrow⇒) Let (xn)(x_n)(xn​) be a sequence in a metric space (X,d)(X,d)(X,d) converging to x∈Xx\in Xx∈X in the metric sense. We know the converse is true in metric spaces. Is it true in general topological spaces?

Example 4.5 Let X=RX=\mathbb{R}X=R be endowed with the countable complement topology: a set U⊆XU\subseteq XU⊆X is open iff X∖UX\setminus UX∖U is countable or U=∅U=\emptysetU=∅.

In metric spaces, the limit of a convergent sequence is unique. Is this true in general topological spaces?

Example 4.7 Let XXX be endowed with the trivial topology τ={∅,X}\tau=\{\emptyset,X\}τ={∅,X}. Then the constant sequence (xn)(x_n)(xn​) with xn=a∈Xx_n=a\in Xxn​=a∈X for all n∈Nn\in\mathbb{N}n∈N converges to every point in XXX.

In general, the limit of a convergent sequence may not be unique. We will need to give some additional conditions on the topology to ensure uniqueness of limits.

Nets

How do we fix this? We need a more general notion of convergence.

Note that a sequence (xn)(x_n)(xn​) in XXX is in fact a function from x:N→Xx:\mathbb{N}\to Xx:N→X. Instead of just using N\mathbb{N}N as the index set, we can use more general index sets.

Definition 4.12 A set Λ\LambdaΛ is a directed set if it is a non-empty set with a relation ≤\le≤ such that

  • reflexive: for all λ∈Λ\lambda\in\Lambdaλ∈Λ, λ≤λ\lambda\le \lambdaλ≤λ,

  • transitive: for all λ1,λ2,λ3∈Λ\lambda_1,\lambda_2,\lambda_3\in\Lambdaλ1​,λ2​,λ3​∈Λ, if λ1≤λ2\lambda_1\le \lambda_2λ1​≤λ2​ and λ2≤λ3\lambda_2\le \lambda_3λ2​≤λ3​, then λ1≤λ3\lambda_1\le \lambda_3λ1​≤λ3​,

  • directed: for all λ1,λ2∈Λ\lambda_1,\lambda_2\in\Lambdaλ1​,λ2​∈Λ, there exists μ∈Λ\mu\in\Lambdaμ∈Λ such that λ1≤μ\lambda_1\le \muλ1​≤μ and λ2≤μ\lambda_2\le \muλ2​≤μ.

This relation ≤\le≤ is called a direction on Λ\LambdaΛ.

Remark 4.13 Note a direction may not be a partial order, i.e., it may not be antisymmetric. For example, let Λ={a,b}\Lambda=\{a,b\}Λ={a,b} with a≤ba\le ba≤b and b≤ab\le ab≤a. This is a directed set but not a poset because a≠ba\neq ba=b.
